# 实现说明 — #1530 评测对照与成本看板

## 需求还原

企业知识库与多 Agent 协作系统（系列 50 单）的拆单之一。本单范围：
**实现六组对照实验结果汇总、回归差异与成本统计**。

验收标准：**提交对照配置、统计口径与可复算样例**。

## 设计

### 1. 对照配置（schema 硬约束）

`schema/eval_board.schema.json`：
- `groups`：`minItems=maxItems=6`（恰好六组）+ 每组 `baseline` 布尔
  （1 个基准组）——从 schema 层锁死"六组对照"验收
- `metrics`：指标名 + `direction`（higher/lower_is_better）
- `cost_model`：`unit_price_usd` + `currency=USD`

### 2. 统计口径（可复算的核心）

| 口径 | 定义 |
|---|---|
| 汇总 | 每组每指标 `mean = Σvalue / n`、`n=样本数` |
| 回归差异 | `delta% = (组均值 - 基准均值) / 基准均值 × 100`，基准=baseline 组 |
| 成本 | `cost = usage × unit_price_usd` |

全部从匿名结果逐行算出，无隐藏口径、无人工调整——买家可拿自己的
数字对账（测试 4 断言 delta=3.8462% 精确命中）。

### 3. 方向标注

每个 delta 带 `direction`（higher_is_better / lower_is_better）——
防止"延迟下降"被误读为坏结果。测试 5 断言 accuracy 方向标注正确。

### 4. 反例与健壮性

- `config-invalid.json`：仅 1 组 / 空指标 / 负成本 / EUR 币种：
  schema 拒绝（测试 7）；`set_config` 同样拒绝（7b）
- 未知组结果 `add_result` 抛错（测试 8）
- 空配置 `summary()≈{}`、`regression_delta()≈{}` 不崩（测试 9/9b）

### 5. 匿名合规

结果为脱敏样例（方法论/路由/分类 A/B 组），无真实实验或客户数据。
