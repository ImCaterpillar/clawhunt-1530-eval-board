# 验收对照 — #1530 评测对照与成本看板

## 验收标准原文

> 提交对照配置、统计口径与可复算样例。

## 逐条对照

| 验收要求 | 交付物 | 验证方式 | run_tests 断言 |
|---|---|---|---|
| 对照配置 | `schema/eval_board.schema.json` + `examples/config.json` | 恰好六组（1 基准）+ 指标方向 + 成本模型 | 1 |
| **统计口径** | `summary()` / `regression_delta()` / `cost()` | 均值/样本数、相对基准 delta%、成本复算 | 3、4、6 |
| **可复算样例** | `examples/results.json`（16 条匿名）| 逐行算出，无隐藏口径 | 2、5 |
| 反例拒绝 | `config-invalid.json` | 缺组/少指标/负成本/非 USD 全被拒 | 7、7b |
| 健壮性 | 未知组/空配置 | 抛错/返回空 | 8、9 |
| 演示 | `demo.py` | 六组汇总+回归+成本（退出码 0）| 10 |
